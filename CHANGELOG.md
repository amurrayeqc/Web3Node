# Changelog

All notable changes to this project are documented here.

## [2.0.0] - 2026-10-07

- Added SHA-256 content-addressed object storage and read-time integrity checks.
- Added deduplication, atomic persistence, HTTP and CLI interfaces.
- Added peer replication, missing-object recovery, and local caching.
- Added automated tests, continuous integration, dependency monitoring, and security guidance.
